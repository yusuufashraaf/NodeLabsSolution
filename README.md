# Node.js Labs

Welcome to the **Node.js Labs Solution** repository!  
Each lab is isolated in its own Git branch to maintain clarity, modularity, and easy tracking of progress.

---

## 📁 Repository Structure

This repository uses a **branch-per-lab** structure. The `main` branch contains general documentation only.  
Each lab's implementation, code files, and setup are available in its corresponding branch.

### 🔀 Branch Naming Convention

| Branch Name | Description                                  |
| ----------- | -------------------------------------------- |
| `main`      | Base branch with README                      |
| `lab1`      | warmUp.js and file operations (studnts.json) |
| `lab2`      | CRUD REST API                                |

> You can switch to any lab branch using:

```bash
git checkout lab1
```
